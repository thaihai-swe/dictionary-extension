# Dictionary Documentation

Welcome to the project documentation.

This repository contains a lightweight Chrome MV3 extension for dictionary lookups, translation, pronunciation, and AI-assisted language learning. It supports multi-source dictionary enrichment, contextual explanations, Grammar & Nuance analysis, phrase/idiom fallback, and structured sentence analysis.
