404

/ˌfɔːr.oʊˈfɔːr/ HTTP status · noun
noun, uncountable · internet error code
  1. 1.

    Not Found: The server cannot find the requested resource. The page may have been moved, renamed, or deleted, or the address was mistyped.

    “We searched all lemmas in our corpus, but this URL returned a 404.”
  2. 2.

    Broken Reading Flow: A detour from reading where expected definitions or context are absent.

    “Don’t let a missing page slow down your comprehension.”
