Free and open source · Load in under 2 minutes

Install locally in Chrome. No account or payment required.

Dictionary is fully open source. You install it directly using Chrome’s unpacked extension workflow. Perfect for personal learning, student labs, and team deployments without store wait times or subscriptions.

  1. 1

    Get the source

    Clone the repository or download the ZIP, then install and build:

    git clone https://github.com/thaihai-swe/dictionary-extension.git
cd dictionary-extension
npm install && npm run build
  2. 2

    Open Chrome extensions

    Navigate to chrome://extensions in your address bar and turn on Developer mode in the top-right corner.

  3. 3

    Load unpacked

    Click Load unpacked and select the built dist directory in the repository.

  4. 4

    Try it on any webpage

    Select any word, click the floating icon, or use the right-click menu. For local HTML files and PDFs, enable Allow access to file URLs in extension details.

Security & Privacy Architecture

Your reading data and credentials never leave your control.

Designed to meet strict privacy standards: zero background telemetry, strictly local credentials, and explicit sentence context boundaries. Safe for workplace and academic use.

Explicit context

Sentence-level, user-approved context

Only the immediate sentence (capped at 800 characters) is extracted when you explicitly invoke a contextual AI action. Ordinary dictionary lookups never transmit sentence context.

Isolated credentials

API keys stay in service worker memory

API keys reside exclusively in chrome.storage.local and background worker memory. Webpage content scripts and popup frames never receive secret keys.

Provider choice

Open models & local endpoints

Point to Google Gemini, Ollama, Groq, OpenRouter, or a local server. You own the endpoint, the model parameters, and the prompt templates.

Zero tracking

No analytics, databases, or surveillance

Lookups exist transiently in the active reading session. The extension does not record reading history, track visited URLs, or phone home.

Frequently Asked Questions

Answers for learners, teachers, and evaluators.

Everything you need to know about keys, triggers, data flow, and product scope.

Do I need an API key to use Dictionary?

No. Dictionary lookups (Wiktionary, Free Dictionary, Datamuse, Tatoeba, Wikipedia), Google translation, and spoken pronunciation practice work 100% free with no keys. An API key is only needed if you want generative AI explanations (Gemini or OpenAI-compatible).

Does Dictionary send the webpage I am reading to AI providers?

No. Standard dictionary lookups send only the queried word. When you click a contextual AI action (like Context Explain or Grammar Nuance), only the single surrounding sentence (capped at 800 characters) is sent. The rest of the page is never read or transmitted.

Is Dictionary an Anki replacement or spaced-repetition (SRS) system?

No. Dictionary is built specifically as an in-situ reading companion: fast lookups, audio practice, and contextual AI on the active page. It keeps you in your reading flow rather than managing flashcard decks or cloud vocabulary lists.

Where are API keys stored and are they safe?

API keys are saved in chrome.storage.local on your device and are accessible only by the extension’s background service worker. They are never synced across devices, never exported in settings backups, and never injected into webpage content scripts.

How do I trigger a lookup on a webpage?

You can highlight text or double-click to show a floating lookup icon (default), tap a modifier hotkey (Shift, Alt, or Ctrl), open the card directly on selection, right-click to choose “Look up in Dictionary”, or search from the toolbar popup. Triggers are automatically suppressed inside form inputs so they never interrupt typing.

What makes the Rephrase feature unique?

Unlike generic AI prompts, a single click on Rephrase returns three targeted rewrite styles in parallel: Simplified, Academic & Formal, and Native Idiom—each paired with explanatory notes in your target language.

Is there a Chrome Web Store listing?

Not yet. Install from GitHub with Chrome’s unpacked-extension workflow: clone the repository, run npm install && npm run build, enable Developer mode, and choose Load unpacked on the built dist folder.
