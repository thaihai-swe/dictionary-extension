A reading workflow, not a destination

From “what does this mean?” to “how do I use it?”

Dictionary keeps the lookup beside the page. It shows the first usable result quickly, then appends contributions from every configured dictionary source as they arrive. Deeper explanations stay one deliberate action away.

1. Select what slowed you down

Highlight text, double-click a word, use the modifier shortcut, open the context menu, or search from the toolbar popup. The resizable card stays beside the source sentence.

2. See every useful contribution

The primary result renders first. Wiktionary, Free Dictionary API, Datamuse, RhymeBrain, Urban Dictionary, and Wiktionary Bilingual continue in the background; usable definitions, examples, audio, and related words are merged into one result.

3. Ask the next useful question

No prompt engineering required. Seven focused AI actions cover meaning in context, grammar, phrase patterns, sentence structure, confusable words, and three Rephrase styles. AI is optional and runs only when you choose an action.

Free and open source

Install it locally in Chrome or Firefox.

There is no account, subscription, or store listing yet. Clone the source, build the browser package, and load the folder using your browser’s developer workflow.

  1. 1

    Get the source

    Clone the repository or download the ZIP, then install and build:

    git clone https://github.com/thaihai-swe/dictionary-extension.git
cd dictionary-extension
npm install && npm run build
  2. 2

    Chrome / Chromium / Edge

    Open chrome://extensions, turn on Developer mode, click Load unpacked, and select the built dist folder. Do not load dist-firefox into Chrome.

  3. 3

    Firefox 115+

    Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on…, and select dist-firefox/manifest.json. Do not load Chrome’s dist into Firefox. Temporary add-ons unload when Firefox quits; load the manifest again after a restart.

  4. 4

    Try it on any webpage

    Select any word, click the floating icon, or use the right-click menu. For local HTML files and PDFs, enable Allow access to file URLs in Chrome extension details or Firefox about:addons. Speech Practice is Chrome-only (no Speech Recognition API in Firefox).

Privacy by default

You choose what gets looked up, cached, and sent to AI.

The extension keeps provider requests, AI context, credentials, and local cache behavior explicit. Ordinary lookups send the selected query to the configured providers; surrounding page context is reserved for an intentional AI action.

Explicit context

Context only when you ask

Contextual AI actions use the immediate sentence, capped at 800 characters. Ordinary dictionary lookups send the selected query, not the surrounding page.

Isolated credentials

Credentials stay in extension storage

AI and translation keys are kept in extension-managed local storage and used by the background service worker. They are not injected into webpage content.

Provider choice

Use the endpoint you trust

Connect Google Gemini or an OpenAI-compatible endpoint such as Ollama, Groq, OpenRouter, or a private local server. The provider, model, endpoint, and prompts are configurable.

Zero tracking

No background tracking

Lookup results can be cached locally for faster repeats. You can disable persistence or clear the cache in Settings; the extension does not record reading history or track visited URLs.

Frequently Asked Questions

The practical details before you install.

Provider behavior, AI context, browser support, settings, and the local installation workflow in one place.

Do I need an API key to use Dictionary?

No. Dictionary lookup across Wiktionary, Free Dictionary API, Datamuse, RhymeBrain, Urban Dictionary, and Wiktionary Bilingual, plus translation and pronunciation, work without an AI key. Configure an AI provider only when you want generative explanations or rewriting.

Does Dictionary send the webpage I am reading to AI providers?

Standard dictionary lookups send the selected query to the configured provider endpoints. When you invoke a contextual AI action, only the single surrounding sentence (capped at 800 characters) is sent. The rest of the page is not included.

Does the extension wait for one dictionary provider?

No. The configured primary source renders first, then the remaining dictionary providers run progressively. Usable definitions, examples, phonetics, and related words are merged into the same result; providers with no usable match are reported as status instead of being presented as contributions.

Can I choose the source, theme, or reading size?

Yes. Settings include the primary dictionary source, translation engine and language, light or dark theme, text size, lookup triggers, popup dimensions, cache persistence, and AI provider configuration.

Is Dictionary an Anki replacement or spaced-repetition (SRS) system?

No. Dictionary is built specifically as an in-situ reading companion: fast lookups, audio practice, and contextual AI on the active page. It keeps you in your reading flow rather than managing flashcard decks or cloud vocabulary lists.

Where are API keys stored and are they safe?

API keys are stored in extension-managed local storage and used by the background service worker. They are not injected into webpage content scripts. Exported settings omit secret keys.

How do I trigger a lookup on a webpage?

You can highlight text or double-click to show the floating lookup icon, use the configured modifier shortcut, open the card directly on selection, right-click to choose “Look up in Dictionary”, or search from the toolbar popup. Triggers are suppressed inside form inputs.

What is the difference between Rephrase and Rewriter?

Rephrase is one of seven AI Assistant intents. One click returns three parallel rewrite styles of the reading sentence: Simplified, Academic & Formal, and Native Idiom—each with a short note. Rewriter is a separate tab for drafting: paste a sentence, email, or short paragraph, pick one of four tones (Formal, Natural, Concise, Casual), and get a polished rewrite plus diagnostic coaching notes. They are not the same feature.

Is there a Chrome Web Store or Firefox Add-ons listing?

Not yet. Install from GitHub: clone the repository, run npm install && npm run build. In Chrome, enable Developer mode and Load unpacked on the built dist folder. In Firefox 115+, open about:debugging#/runtime/this-firefox and load dist-firefox/manifest.json as a temporary add-on.
