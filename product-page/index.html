Designed around real reading problems

One extension for the questions that interrupt comprehension.

Each capability exists to remove a common source of friction: an unknown word, two words that look alike, a phrase that cannot be translated literally, or a sentence whose grammar changes the meaning.

A

Definitions with useful detail

Entries can include parts of speech, examples, synonyms, antonyms, IPA, word-family chips, and provider badges so the answer is both useful and attributable.

B

Translation in the same result

See a target-language translation alongside the dictionary result instead of switching tools for every unfamiliar term.

C

Pronunciation and speech practice

Play dictionary audio with speech-synthesis fallback, then speak the word back and get a color-coded accuracy grade.

D

Phrase-aware recovery

For multi-word expressions, the lookup chain can try normalized lemma and phrase candidates and use an AI phrase explanation when structured results are incomplete.

E

Context you can inspect and click

Sentence context is an editable prefill, not hidden scraping. Words in Context used are clickable for nested lookups, and follow-up sections load with a visible progress strip.

F

Seven named AI actions

Dedicated actions cover senses in context, grammar slots, phrase patterns, sentence structure, confusable comparisons, three rewrite styles, and in-place section regeneration—not a blank chat box.

Free to install · no Chrome Web Store listing yet

Load Dictionary locally in Chrome in a few minutes.

The extension is open source. GitHub Pages hosts this product page. You install from the repository with Chrome’s unpacked-extension workflow—no account, no payment, no store review wait.

  1. 1

    Get the source

    Clone the repository or download the ZIP and open the dictionary-extension folder.

    git clone https://github.com/thaihai-swe/dictionary-extension.git
  2. 2

    Open Chrome extensions

    Go to chrome://extensions and turn on Developer mode in the top-right corner.

  3. 3

    Load unpacked

    Click Load unpacked and select the cloned repository folder (the one containing manifest.json).

  4. 4

    Try it on a real page

    Select a word, open the toolbar popup, or use the context menu. For local files and PDFs, enable Allow access to file URLs in the extension details.

Privacy and control are product features

You decide what is sent, where it goes, and what stays on your device.

The extension separates normal preferences from credentials and keeps contextual AI requests explicit. The goal is useful assistance without turning your reading into a hidden data source.

Explicit context

Context is opt-in

Page context is a sentence-level prefill you can replace. It is sent only when you choose a contextual AI action, not during ordinary dictionary or AI lookup.

Local credentials

Keys are isolated

Provider and AI API keys live in chrome.storage.local and stay in the background service worker. The toolbar popup and the reading page only load non-secret preferences.

Provider choice

Configure the services you use

Dictionary, translation, AI endpoint, model, and prompt templates are configurable. AI remains optional if you only want dictionary and translation.

No hidden history

Keep learning in the moment

Context stays transient for the active popup session. The extension does not create a permanent database of page context or raw AI payloads.

ReliabilityDesigned for asynchronous reading

Dictionary and translation work can complete independently. Secondary-provider enrichment is bounded, deduplicated, and merged only when it still belongs to the active query.

  • Stale-response guards match request ID and query text.
  • Cancellation is silent during rapid consecutive lookups.
  • Operational provider failures remain distinct from “not found” fallbacks.

MaintainabilitySimple, explicit boundaries

Provider-specific parsing stays in adapters; shared rendering stays in the UI layer; the service worker coordinates messages and caching. The project uses plain HTML, CSS, and JavaScript by design.

  • Normalized provider contracts keep the renderer provider-agnostic.
  • Storage validation and migrations keep settings durable across MV3 restarts.
  • Shared popup helpers keep toolbar and in-page behavior aligned.

// Providers return one renderer-compatible result shape.
const primaryId = settings.dictionaryProvider || "free_dictionary";
const adapter = DICTIONARY_PROVIDERS[primaryId];

try {
    return await adapter.lookup(text, settings, options);
} catch (error) {
    // Only a real “not found” result moves to a dictionary fallback.
    if (error instanceof NotFoundError) {
        return lookupFallbackChain(text, settings, options, [primaryId]);
    }
    throw error;
}
